# SilentRadar

Web de producto para un SaaS universitario colaborativo, con acceso integrado al directorio real. Dirección visual aprobada: inicio comercial, Qué somos, Cómo funciona y espacios en vivo; acabado premium y animaciones cuidadas. Fondo claro mineral, verde bosque, acentos salvia y tipografía Newsreader con cursiva auténtica para títulos, Public Sans para controles.

El inicio presenta el producto con una vista previa interactiva alimentada por el snapshot real. El radar abstracto acompaña la marca: sus cuatro puntos reflejan estados acústicos, no posiciones geográficas. Los contadores siempre derivan de datos reales; no hay testimonios, usuarios, tendencias ni métricas inventadas.

La navegación usa anclas reales con header fijo y menú móvil. El directorio ofrece filtros, búsqueda y vistas de tarjetas/lista; el formulario conserva validación, idempotencia y actualización en vivo. Animaciones de entrada, revelado por scroll, radar y hover; respetar prefers-reduced-motion. Ningún servicio de pago ni dependencia de animación nueva.

Referencias 21st previas: List Group Badge (29345) y Status (25394), metadata. Para el rediseño se consultaron Dashboard Sidebar (14941), App Dashboard Layout (28770) y otras shells; se revisó el código de Dashboard Sidebar usando una recuperación gratuita disponible. Se tomó como referencia la jerarquía y el espaciado de superficies; la implementación se escribió para este producto, con Radix y Lucide ya instalados. No se consumió generación alojada ni recuperación de pago.
