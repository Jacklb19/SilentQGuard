# SilentRadar

Directorio universitario para encontrar lugares de estudio. Estética editorial y señalética: fondo cálido, verde profundo, Newsreader para títulos y Public Sans para controles. Lista compartida con separadores, esquinas discretas y controles accesibles. Priorizar comparar cuatro espacios, reportar percepción y conocer la conexión.

Referencias consultadas en el catálogo gratuito 21st: List Group Badge (29345) y Status (25394), únicamente metadata. Se toma como inspiración la densidad de lista y etiqueta de estado; no se reutiliza código de terceros ni se consume generación o recuperación de pago. Sin pulsos constantes.
